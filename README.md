# RatoPay - SYP Project

Student Name: Bibek Parajuli

## About the Project
RatoPay is my Second Year Project (SYP). It is a simple digital wallet and payment gateway system where users can create a wallet account, view their debit card, and make test payments on a merchant website.

## Current Progress
- Created initial ERD and Gantt Chart
- Designed basic UI wireframes (Login page, Wallet home, and Dashboard)
- Set up project repository and started working on the Login page

## Tech Stack
- React / TypeScript
- React Native (Expo)
- Firebase (Auth and Firestore)
